Welcome

Goalify Companion reads Goalify's saved observations after you log out or use /reload. Enable Community Sharing in Goalify, choose an account below, review its preview, tick consent and select Send. Contributions help improve community source data for everyone.

Sent: NPC and item IDs and names, vendor offers, loot methods, trainer professions and factions, approximate map locations, observation timestamps, client build, addon version and locale. An anonymous install token is used to authenticate.

Never sent: account, character or realm names, GUIDs, goals, gold, inventory, mail or notes. An optional contributor display name is sent only if you choose to save it.
