Welcome to Goalify Companion

One Goalify, two connected tools. The Goalify addon manages your goals in game. This optional desktop companion shares permitted discoveries to help improve community source data. Install the addon separately.

Goalify Companion reads Goalify's saved observations after you log out or use /reload. Enable Community Sharing in Goalify, then tick consent for an account below. By default new observations are sent automatically while this app is open; you can preview any batch first, or switch to manual sending in Settings. Contributions help improve community source data for everyone.

Sent: NPC services and guard questions, guard-reported destinations and transport tags, training offers and costs, flight nodes, vendor offers, loot methods, trainer professions, approximate locations, observation timestamps and captured builds. Addon version and locale accompany an anonymous install token.

Never sent: account, character or realm names (matching text is removed before preview), GUIDs, training availability or learned status, unlocked or reachable flight paths, goals, balances, inventory, mail or notes. An optional contributor display name is sent only if you choose to save it.

How to send
        
        
      

      
Automatic sending only covers accounts you consented to that also have Community Sharing on in game. It checks when the app opens, every 10 minutes and when you select Refresh. Nothing is sent while the app is closed. A failed batch is retained and retried.

      
      

      
Deleting shared data removes this install and its observations from the service, then clears local credentials and consent.
